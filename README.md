# Académie IA — Dossier de démarrage Codex

Ce dépôt contient le prototype HTML V9 validé et les spécifications du passage à une application réelle.

## Fichiers
- `prototype-v9.html` : référence visuelle et fonctionnelle (simulation front-end uniquement).
- `SPECIFICATION.md` : périmètre, règles métier, sécurité, étapes et critères d'acceptation.
- `PROMPT_CODEX.md` : instruction de départ à donner à Codex.

Le prototype n'est **pas** une plateforme de production. Il stocke des données locales fictives, simule les paiements et les contrôles d'accès. Ne pas publier ce HTML comme site payant sans implémentation serveur sécurisée.

## Ordre de réalisation
1. Examiner le prototype et dresser la carte des pages, modules, états et interactions.
2. Générer l'application responsive avec des données de démonstration et une base de tests.
3. Ajouter authentification, back-office, contenu, quiz et progression persistants côté serveur.
4. Ajouter paiement, abonnements et contrôle d'accès côté serveur.
5. Ajouter Club IA multi-utilisateurs, modération et publication.
6. Vérifier, sécuriser puis déployer progressivement.

Ne pas inventer les 132 vidéos ni les cours détaillés manquants : créer des emplacements éditables dans l'administration.
